# 短信转发（SmsRelay）

把安卓手机收到的短信，实时转发到 iPhone（通过 [Bark](https://github.com/Finb/Bark)）或飞书群。

适合这种情况：手上有两台手机，一张卡放在安卓机里，不想随身带着它，又要能及时看到短信和验证码。

> 主要在 realme（realme UI / ColorOS 系）手机上测试，其他安卓手机一般也能用，后台设置的位置可能不同。

## 基本功能

- **实时转发**：收到短信后 1~2 秒就推送出去，锁屏时也能转发（要按下面的「注意事项」设置好）
- **两种转发渠道**，可以同时开：
  - **Bark**：iPhone 上弹出通知，验证码可以一键复制；支持**加密推送**，Bark 服务器和苹果都看不到短信内容
  - **飞书群机器人**：发到飞书群里，支持签名校验
- **自动识别验证码**：短信里有验证码时，单独显示在标题里，Bark 通知长按就能复制
- **推送模板**：内置 5 种样式（标准、验证码优先、详细信息、极简、隐私），也可以自己写，能用的参数有：
  `{验证码}` `{发件人}` `{卡号}` `{时间}` `{短信内容}` `{手机名称}`
  （用 `[ ]` 括起来的一段，里面的参数为空时整段不显示，比如 `[验证码 {验证码} · ]`）
- **双卡**：能区分是卡 1 还是卡 2 收到的
- **长短信**：被拆成几段的长短信会自动拼回一条
- **断网补发**：发送时没网，会等联网后自动补发，最多重试 10 次
- **权限检查**：首页列出转发需要的每一项权限和设置，没设置好的会标红，点「去开启」直接跳到对应的设置页
- **最近记录**：显示最近 50 条转发是成功还是失败，失败的会写原因
- **开机自启**：手机重启后自动开始工作

## 使用教程

### 1. 安装

本项目没有上架应用商店，需要自己编译安装：

1. 安装 [Android Studio](https://developer.android.com/studio)
2. 下载本项目代码，用 Android Studio 打开
3. 安卓手机打开「开发者选项」里的「USB 调试」，用数据线连上电脑
4. 点 Android Studio 上方的 ▶ 运行，App 就会装到手机上

也可以用命令行编译：`./gradlew assembleDebug`，生成的安装包在 `app/build/outputs/apk/debug/app-debug.apk`，发到手机上安装即可。

要求：Android 8.0 及以上。

### 2. 设置转发渠道

**Bark（推荐，转发到 iPhone）**

1. iPhone 在 App Store 安装 **Bark**
2. 打开 Bark，复制首页上的地址（形如 `https://api.day.app/xxxxxxxx/`）
3. 在安卓手机的「短信转发」里，打开 Bark 开关，粘贴这个地址
4. （可选）加密推送：在「短信转发」里点「随机生成」得到 32 位密钥，点「复制」；
   然后在 iPhone 上打开 Bark：首页 → 推送加密 → 加密设置，算法选 **AES256**，模式选 **GCM**，Key 粘贴同一个 32 位密钥，IV 随便填 12 位，点完成

**飞书群机器人**

1. 飞书群设置 → 群机器人 → 添加机器人 → 自定义机器人
2. 复制 Webhook 地址，粘贴到「短信转发」的飞书设置里
3. 如果机器人开了「签名校验」，把密钥也填上

设置会自动保存。填好后点 **「发送测试消息」**，iPhone 或飞书收到了就说明设置成功。

### 3. 完成权限检查

打开 App，首页「权限检查」里每一项都要是 ✅。没通过的，点右边的「去开启」按提示设置：

| 项目 | 作用 |
|---|---|
| 接收和读取短信 | 没有这个权限就收不到短信 |
| 通知使用权（锁屏时唤醒） | 在列表里找到「短信转发（锁屏唤醒）」并打开，锁屏时也能及时转发 |
| 通知 | 显示「正在后台监听短信」的常驻通知 |
| 不限制后台耗电 | 防止系统在后台限制本 App |
| 后台可以使用网络 | 开了省流量模式时，要允许本 App 在后台联网 |
| 后台服务正在运行 | 本 App 正在工作 |
| 已设置转发渠道 | Bark 或飞书至少开了一个 |

全部通过后会显示「✅ 全部通过，可以正常转发」。

### 4. 手机后台设置（很重要）

国产手机会清理后台 App，不设置的话过一段时间就收不到转发了。以 realme 为例：

1. **设置 → 应用 → 应用管理 → 短信转发 → 耗电管理**：打开「允许后台运行」「允许自启动」「允许关联启动」
2. 打开最近任务（屏幕底部上滑停住），长按「短信转发」的卡片，点 **「锁定」**
3. **关闭「锁屏后断网」**：在设置顶部搜索「断网」或「锁屏」找到它并关掉
4. 不要关掉通知栏里「正在后台监听短信」这条常驻通知

其他品牌的手机，设置名字可能不一样，一般在「应用管理」「电池」「耗电保护」这几个地方。

## 注意事项

- **锁屏后要等解锁才收到转发？** 九成是「锁屏后断网」没关。realme / OPPO / 一加手机默认开着，锁屏一会儿就断网，短信只能等解锁后才发出去。关掉后锁屏也能实时转发
- **隔一段时间就不转发了？** 是被系统清理后台了。按上面第 4 步逐项设置，尤其是「锁定」和「允许自启动」
- **「最近记录」里显示失败？** 看后面写的原因：地址不正确、密钥不对之类的是设置问题，改好再点「发送测试消息」试试；没网时会自动补发，不用管
- **加密推送收到乱码或收不到？** 检查 iPhone 上 Bark 的加密设置：AES256、GCM，密钥和安卓上的完全一样
- **隐私**：短信只在你的手机和你自己设置的 Bark / 飞书之间传，本 App 没有自己的服务器，不收集任何数据。Bark 地址、飞书地址和密钥只保存在手机上。如果担心第三方服务器看到短信内容，可以：
  - 开启 Bark 加密推送
  - 或者用「隐私」模板，只推送「收到 xxx 的短信」，不带短信原文
- **不要把你的 Bark 地址或飞书 Webhook 地址发给别人**，拿到地址的人可以往你的手机推送消息
- 本 App 只转发**新收到**的短信，不会转发以前的短信，也不能发短信

## 技术说明

- Kotlin + Jetpack Compose，最低 Android 8.0（API 26）
- `SmsReceiver` 接收短信广播；`WakeListener`（通知监听）在短信 App 弹通知时再读一次收件箱作为兜底，两边靠 `Dedupe` 去重
- `KeepAliveService` 是常驻前台服务，降低被后台清理的概率
- 发送失败交给 WorkManager，联网后自动重试
- Bark 加密使用 AES-256-GCM，和 Bark 的「推送加密」设置对应
